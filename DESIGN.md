# Compel public website

## Current direction

A clear, conversational studio website for established coaching businesses. The hero leads with the booking outcome and performance offer. The page shows how a visitor gets to a call, details the P.A.C.E. rebuild, and invites visitors to request a free review.

## Visual contract

- Matte charcoal `#121510`, warm-white text `#f2f5eb` and Compel lime `#b1ff00`. The illustrated booking experience uses a light surface for contrast.
- The supplied Focura reference informs the hero background only: two broad, tapered, softly blurred lime light streaks enter diagonally from the edges. Built in CSS, with a clear center for the headline. No background image, UI mockup or generated artwork.
- The navbar is one compact rounded charcoal container containing exactly the wordmark and review action. No links, menu or secondary text. The keyboard skip link remains outside the container.
- The centered hero leads with the booked-call guarantee. Manrope carries the interface and Instrument Serif emphasises the payment condition. Eligibility and measurement are agreed before work starts.
- The main action is a warm-white button with a lime circular arrow inset. The compact navbar action uses lime. Hover only changes the surface color. No movement, scaling, shimmer, glow, magnetic tracking or animated arrow.
- The problem title is centered above the copy, with underlines and a highlight marking key phrases. The solution shows an example offer, booking, and confirmation in one illustrated sequence. The supporting research follows, with sources in `content/home-research.md`.
- The P.A.C.E. section aligns four stage letters beside their descriptions and deliverables in one connected panel.
- The navbar, hero, and P.A.C.E. actions each reveal a compact website form beneath the triggering button. The closing form is visible on arrival. Other public pages use the review modal.
- Public routes use the same matte-and-lime palette. Secondary public pages retain their compact colophon. Private proposals have their own styling.

## Verify

Inspect the page at 1440, 1024 and 390px. Check beam placement, text contrast and highlights, the two-item navbar, static button feedback, and the inquiry form's focus, validation and close behavior. Run the production build and existing lead/proposal tests. Do not submit a real lead during visual QA.
